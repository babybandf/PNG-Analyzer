# WP-603A — Parser/Stream Fuzz Smoke

Status: **implemented** (2026-08-23)

The repository now has a deterministic `tests/fuzz` target that generates 512
xorshift inputs from seed `0x603a2026`, each capped at 4 KiB. Every input is
sent through `ChunkIndex`, `validate_document`, bounded Virtual IDAT reads and
the zlib-wrapper trace parser. The harness asserts stream-read and total-size
invariants and never writes generated bytes into the reviewed corpus.

This is a reproducible parser/stream smoke foundation for later coverage-guided
and sanitizer jobs; it does not claim coverage-guided fuzzing or a complete
regression corpus. A failure can be replayed by running the same Catch2 test,
because the seed and iteration count are fixed in source.
